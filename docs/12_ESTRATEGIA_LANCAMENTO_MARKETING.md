# 📣 ESTRATÉGIA DE LANÇAMENTO E COMUNICAÇÃO

**Criado em:** 16/08/2026
**Contexto:** complementa `11_PLANO_IMPLEMENTACAO.md` (o que construir) e
`06_VISAO_LONGO_PRAZO.md` (pra onde vai) — este documento é sobre COMO
entregar isso pra pessoas de verdade em Lumiar e São Pedro da Serra, na
ordem das 3 waves já decididas.

---

## 🎯 A mensagem central (uma frase)

```
"Lumiar já resolve isso no grupo de zap — só que perdido. Isso aqui é
o mesmo grupo, organizado."

Não é vender algo novo. É organizar algo que a comunidade já faz
(indicar prestador no grupo de WhatsApp) de um jeito que não some
depois de um dia de mensagens.
```

Isso importa porque muda o tom de toda comunicação: você não está
convencendo ninguém de uma necessidade nova, só mostrando uma versão
melhor de um hábito que já existe. É uma venda muito mais fácil.

---

## 👥 Proposta de valor por público

### Pra quem procura serviço (morador)

```
├─ Não precisa mais rolar histórico de grupo tentando lembrar quem
│  alguém indicou mês passado
├─ Busca por categoria, cai direto no WhatsApp de quem presta —
│  sem intermediário, sem cadastro só pra olhar
└─ Vai crescendo: hoje é diretório, depois carona compartilhada,
   quentinha do dia, cursos, alerta de chuva forte
```

### Pra quem presta serviço

```
├─ Grátis pra sempre, sem comissão nenhuma
├─ Cliente fala direto com você — você não perde o contato pra
│  nenhum intermediário
├─ Fica sempre buscável (diferente do grupo, onde a mensagem
│  desaparece depois de um dia)
└─ Cadastro leve — sem CPF, sem endereço, sem burocracia
```

## 📡 Canais por wave (mapeado à `06_VISAO_LONGO_PRAZO.md`)

```
WAVE 1 (10-20 pessoas) — não é "marketing", é conversa
├─ Canal: WhatsApp 1:1 ou pessoalmente, do Rafa pra cada pessoa
├─ Enquadramento: "tô construindo isso pra gente, testa e me fala
│  o que acha" — não é lançamento, é convite pra ajudar a construir
└─ Objetivo: feedback real, não alcance

WAVE 2 (50-100 pessoas) — ainda dentro do círculo de confiança
├─ Canal: prestador já cadastrado indica outro prestador
├─ Mensagem já pode ser um pouco mais "pronta" (ver rascunho abaixo),
│  mas ainda pessoal — não é post público
└─ Objetivo: primeiras Colunas postadas, Alerta rodando, prova de uso

WAVE 3 (público) — aqui sim é comunicação de lançamento
├─ Canal: grupos de WhatsApp/Facebook da região
├─ Só dispara quando os 4 critérios da Estratégia de Lançamento
│  Gradual já estiverem batidos (50+ serviços, 3+ Colunas, Alerta
│  estável há 1 semana, invite codes testados)
└─ Objetivo: alcance real, com prova social já visível no app
```

## 🔮 "O que já dá pra usar" vs "o que vem por aí"

```
Regra: nunca prometer o que ainda não existe como se já existisse.
Framing honesto: "conforme mais gente for entrando, vamos soltando
[funcionalidade]" — sem data fixa, sem overpromise.

JÁ DÁ PRA USAR (V0):
├─ Busca de prestador por categoria, com filtro
├─ Perfil do prestador com foto, descrição, botão de WhatsApp
├─ Aba Úteis: ônibus, clima, telefones úteis
└─ Cadastro de prestador leve (2 passos, sem burocracia)

VEM POR AÍ (mencionar como horizonte, não promessa):
├─ Carona compartilhada
├─ Quentinha do dia / menu do dia em destaque
├─ Alerta de chuva forte / risco de deslizamento
├─ Colunas — prestador compartilhando dica/expertise
└─ Selo de "confirmado pela comunidade"
```

## 🤝 Como as pessoas ajudam a melhorar

```
Early adopters (Wave 1 e 2) devem se sentir "fundadores", não
"usuários número 47". Isso aumenta retenção e boca a boca de forma
desproporcional ao esforço — pessoas defendem o que ajudaram a criar.

├─ Botão "Enviar sugestão" (já no escopo do V0) — reforçar o uso
│  ativamente, não só deixar ele existir passivo no menu
├─ WhatsApp pessoal do Rafa como canal direto nas Waves 1 e 2 —
│  informal, alta resposta, mais valioso que qualquer formulário
└─ Quando uma sugestão de alguém da Wave 1/2 virar funcionalidade de
   verdade, vale mencionar quem sugeriu (com permissão) — reforça
   que o feedback importa e puxa mais gente a participar
```

## 📍 Ponto de contato físico (não só digital) — FUNDAMENTAL, não só "boa ideia"

```
Confirmado pelo Rafa: isso não é complemento, é essencial pra
comunidade de montanha — nem todo mundo tá o tempo todo plugado em
grupo de WhatsApp ou rede social.

├─ QR code em local de alto tráfego: mercadinho, padaria, ponto de
│  ônibus, posto de gasolina, igreja
├─ Mensagem física simples: "Central de prestadores de Lumiar/SPS —
│  aponte a câmera e ache quem você precisa"
└─ Baixo custo (impressão simples), alcança quem o digital sozinho
   não pega — especialmente moradores mais velhos, que também são
   quem mais usa boca a boca pra indicar serviço
```

## 📣 Influenciadores locais

```
Ideia nova desta sessão: usar quem já tem alcance/confiança na
comunidade (perfil pessoal com seguidores locais, dono de comércio
conhecido, liderança comunitária) como amplificador — pedir pra essa
pessoa compartilhar/testar antes da Wave 3, não só postar sozinho nos
grupos.

├─ Agora: mapear quem em Lumiar/SPS já tem esse alcance local e
   trazer pra Wave 1 ou 2 (não esperar a Wave 3 pra envolver)
└─ Futuro (ver `06_VISAO_LONGO_PRAZO.md`, seção "Ponto de decisão:
   escalar como?"): se/quando o pacote for replicado pra outra
   cidade pequena, o mesmo padrão se repete lá — mapear influenciador
   local DAQUELA cidade, não tentar alcançar de fora. É a mesma
   lógica de "replicar o pacote" aplicada à parte de comunicação, não
   só ao produto.
```
